# Buran MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the buran MVP — a minimal ACP agent harness in Rust (`buran serve` headless ACP server + `buran-tui` TUI client) with MCP tools, AGENTS.md injection, skills, config, and first-run doctor.

**Architecture:** Three fixed layers: ACP (agent-client-protocol crate) between client and agent over stdio; MCP (rmcp) between agent and tools spawned from `.mcp.json`; all HTTP via hclient with SSE streaming for OpenAI-compatible chat completions. One tokio process per binary; LLM loop and tool execution live agent-side; filesystem/terminal live client-side per ACP.

**Tech Stack:** Rust 2024 edition, tokio, hclient 0.1.0-alpha.20 (+ hclient-mock dev), agent-client-protocol (Zed), rmcp 3.9.0, clap, thiserror/anyhow, ratatui+crossterm (TUI binary only), tracing+tracing-subscriber (stderr/file only).

**Spec:** `AGENTS.md` (repo root, fetched from https://github.com/GamePad64/buran — copy it into the repo as the first commit so the spec travels with the code).

## Global Constraints (from AGENTS.md — every task implicitly includes these)

- Rust edition 2024; `rust-toolchain.toml` = `channel = "stable"`, `components = ["rustfmt", "clippy"]` — never pin a version.
- `cargo clippy -- -D warnings` and `cargo fmt --check` must pass at every commit.
- HTTP only via hclient (`features = ["default-transport"]` + `json`). Forbidden: reqwest, any other HTTP client, hand-rolled SSE parsing, provider SDKs, wasmtime/extism.
- Tests never spawn real HTTP servers; LLM streaming tests use `hclient-mock` (`MockTransport` + `push_response_frames`).
- Never write to stdout under `serve` — stdout is the ACP JSON-RPC channel. Logs go to stderr/file only.
- No blocking sync I/O on stdio flows inside tokio context — use `tokio::io` / `spawn_blocking` for child-process stdin/stdout.
- No built-in agent tools in the binary (sole exception: bundled filesystem MCP server for ACP graceful-degradation fallback — and that one is also an MCP server, just bundled).
- No per-provider logic in code — providers differ only by config (base_url, api_key, model).
- American English everywhere; conventional commits (`feat:`, `fix:`, `docs:`, `chore:`); errors: thiserror for library types, anyhow at CLI boundary.
- License: MIT — add LICENSE file.

## Review Focus

- **Empty/missing API key at `serve` startup** — must fail fast with a clear stderr error pointing at the config file and env var, not hang or emit garbage into the ACP channel.
- **Malformed `.mcp.json` / `config.toml`** — a broken project config must produce a named error (file, JSON path, reason) and degrade (skip that server / use defaults), not crash the server; doctor reports it.
- **MCP server that fails to spawn or hangs on handshake** — `tools/list`/`tools/call` must time out and surface a per-server tool-error to the model, never block the LLM loop forever.
- **SSE stream that ends without `[DONE]` or errors mid-stream** — LLM loop must finalize the turn gracefully (end_turn with partial text), not panic or loop.
- **ACP client that disconnects mid-prompt** — must cancel the in-flight LLM loop and MCP calls, clean up session state, exit code 0 on EOF.

```rust
use clap::{Parser, Subcommand};

#[derive(Parser)]
#[command(name = "buran", about = "Lightweight ACP agent harness", version)]
struct Cli {
    #[command(subcommand)]
    command: Option<Command>,
}

#[derive(Subcommand)]
enum Command {
    /// Run the headless ACP agent server on stdio (default)
    Serve,
    /// Probe config and MCP servers, offer ACT on first run
    Doctor,
    /// List configured MCP servers and their tools
    Mcp {
        #[command(subcommand)]
        cmd: McpCommand,
    },
}

#[derive(Subcommand)]
enum McpCommand {
    /// List MCP servers from config and .mcp.json
    List,
}

fn main() -> anyhow::Result<()> {
    let cli = Cli::parse();
    match cli.command.unwrap_or(Command::Serve) {
        Command::Serve => {
            buran::run::serve()
        }
        Command::Doctor => {
            buran::run::doctor()
        }
        Command::Mcp { cmd } => match cmd {
            McpCommand::List => buran::run::mcp_list(),
        },
    }
}
```

- [ ] **Step 3: Implement config.rs**

```rust
use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

use serde::Deserialize;

#[derive(Debug, thiserror::Error)]
pub enum ConfigError {
    #[error("failed reading {path}: {source}")]
    Io {
        path: PathBuf,
        source: std::io::Error,
    },
    #[error("failed parsing {path}: {source}")]
    Parse {
        path: PathBuf,
        source: Box<dyn std::error::Error + Send + Sync>,
    },
    #[error("provider config incomplete: set base_url, model, and api_key or api_key_env (in {file})")]
    ProviderIncomplete { file: PathBuf },
    #[error("api key env var {var} is not set")]
    ApiKeyEnvMissing { var: String },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ApiKey {
    Explicit(String),
    FromEnv(String),
}

impl ApiKey {
    pub fn resolve(&self) -> Result<String, ConfigError> {
        match self {
            ApiKey::Explicit(s) => Ok(s.clone()),
            ApiKey::FromEnv(var) => {
                std::env::var(var).map_err(|_| ConfigError::ApiKeyEnvMissing { var: var.clone() })
            }
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ProviderConfig {
    pub base_url: String,
    pub model: String,
    pub api_key: ApiKey,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct McpServerConfig {
    pub name: String,
    pub command: String,
    pub args: Vec<String>,
    pub env: BTreeMap<String, String>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum PermissionPolicy {
    AllowAll,
    DenyAll,
    #[default]
    Ask,
}

#[derive(Debug, Clone)]
pub struct Config {
    pub provider: Option<ProviderConfig>,
    pub mcp_servers: Vec<McpServerConfig>,
    pub skills_dirs: Vec<PathBuf>,
    pub bundled_fs_server: bool,
    pub permission: PermissionPolicy,
}
```
plus `#[derive(Deserialize)]` mirror structs with `#[serde(default)]`, a `TomlFile`/`McpJsonFile` pair, the merge logic above, and `pub fn load(project_dir: Option<&Path>) -> Result<Config, ConfigError>` that:
1. reads global `~/.config/buran/config.toml` if present (`dirs`-free: `std::env::var("HOME")` on unix; on Windows use `%APPDATA%`), remembers provider as base;
2. reads `buran.config.toml` in project dir if present, overriding provider fields and appending skills dirs;
3. reads `.mcp.json` in project dir if present, appending servers (project name collision wins, keep first-seen order);
4. if env `BURAN_API_KEY` set, replaces `ApiKey` with `FromEnv("BURAN_API_KEY")`;
5. applies defaults (`bundled_fs_server = true`, `permission = Ask`).
